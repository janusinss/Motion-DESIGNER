# Creative Direction Engine (Award-Level)

Read in **Step 2**. This file turns a topic into a *film*. The technical stack (catalog.md) decides HOW it is built; this file decides WHAT the film is, and that decision is what separates a festival-grade piece from a template. - `.agents/skills/motionmaxxing/references/slop.md` + `.agents/skills/cinetic/references/taste-and-slop.md` — what reads as AI-made

## Part A — The 10-Move Direction Engine

Run all ten moves silently, then write the results into Section 1 of the Prompt-Plan. Every move produces one concrete line; "TBD" is not allowed.

### Move 1 — PAGE (the brief behind the brief)
| | Question | Decides |
|---|---|---|
| **P**roblem | What true, annoying situation does this change? (a situation, not a feature) | whether a beat earns its place |
| **A**udience | Who watches, where, in what state? (muted feed at 1 a.m., buyer on a call, festival screen) | pace, density, type size, sound on/off |
| **G**oal | The one thing they do, think, or repeat afterwards | structure and the ending |
| **E**motion | Start feeling → end feeling (sceptical → relieved, bored → delighted) | music, pace, weight, colour |

The **emotional delta is the payload**; features are the vehicle. Bigger delta = stronger film.

### Move 2 — Inventory (where the idea hides)
Write one line each; "none" is an answer:
1. **The name's meaning** — etymology, second meaning, the physical thing it names.
2. **The non-obvious behaviour** — finish "Unlike the obvious version, it …". This becomes the proof beat.
3. **The key verb** — split, ship, fold, find, steady. Can motion *perform* it?
4. **The signature material** — what the screen/world fills with (code, receipts, maps, fabric, waveforms).
5. **The one number** — 412 → 1, 3:12 → 3:13, 14,000 → 40.
6. **The success frame** — what is on screen at the moment it works. Build the film backwards from it.
7. **The voice** — read the brand's headlines aloud: deadpan, warm, cocky, technical.
8. **Category clichés** — the 5 images every competitor uses. They are **banned** for this film.

### Move 3 — Three concepts of three different KINDS
Write the first idea, then **discard it** (it is nearly always the category costume). Write three more, each as **one sentence that predicts what happens on screen** ("premium, smooth, cinematic" predicts nothing), each a different kind:

| Film kind | Shape | Wins when |
|---|---|---|
| UI documentary of one real task | one real case, question → result, the camera explains | product is a tool people operate |
| Single held shot that slowly changes | one take, something transforms under the camera | one object/material carries the brand |
| Joke with a character | deadpan problem, product as straight man | playful voice, relatable pain |
| Typographic essay | the words ARE the picture and perform their meaning | value is a sentence; brand is a voice |
| Montage of real output | many real results cut to rhythm | product makes beautiful, varied things |
| Stillness that breaks | calm held → one cause breaks it → calm, smaller | brand sells relief, focus, silence |
| Counter as spine | one number counts through the whole film | product reduces, sorts, adds up |
| Bookend | same image + sound first and last, one thing changed | before/after promise |
| One unbroken take | a single camera descent / pull-back / track | products about depth, scale, flow |
| Scale jump | the same object at 16 px and full frame | small unit adds up to something big |
| Claim → cut → proof → CTA | claim in type, hard cut, product performs it | one operable action + one sentence (the default; never the only one considered) |
| Transformation chain | A → B → C → logo | **rarely** — only when the product IS a transformation (most over-used shape) |

### Move 4 — Kill tests (run on every concept)
| Test | Fails when |
|---|---|
| **Cover the logo / competitor swap** | the film still works for a competitor with colours changed |
| **Mute** | picture alone cannot tell problem → result |
| **One sentence** | the idea needs "and" (two ideas) or an adjective (a style) |
| **Specificity** | the film would be equally true of a simpler, naive product |
| **Poster** | the final frame, printed on a wall, doesn't say who made it and what it does |
| **Retell** | a viewer would describe a style ("it was slick") instead of an image ("the card that folded 412 alerts") |
| **Truth** | the picture promises something the product does not do |

Score survivors 0–3 on **ownership, muted clarity, device strength, surprise, buildability**. Pick the highest with ownership ≥ 2; break ties toward buildability. **Choose, never average** — but graft one element from a loser (a line, an opening image) and name it.

### Move 5 — The Concept Triad
- **Idea** (≤ 8 words): what the viewer believes afterwards.
- **Device**: the ONE owned thing that carries the idea through every shot (from, in order of preference: a product object with states → the name's meaning → the number → a primitive of the mark). It must change state (tick, fill, fold, lock), travel small, fill the frame once, and end as the mark or the resolved unit.
- **Grammar**: the rule the film's *form* obeys ("everything moves vertically under gravity until the lockup"; "after the turn, the film only gets quieter"; "the horizon never tilts"). Grammar is where a film becomes ownable.
- **Logline** (≤ 15 words, seen not described): *device + what it does + the turn + the result*.
- **Idea sentence**: "In this film, **[something only this subject has]** becomes **[the device]**."

### Move 6 — Hero moment & signature shot
Name the **one frame someone would screenshot and send to a friend**, its beat, and how it is made (≥ 3 concrete quantities: frames, px, degrees, factors). It happens **once**, at **60–75 %** of runtime, and gets the hardest work (scale, camera, sound, light event). If you cannot name it, the film has no centre — return to Move 3.

### Move 7 — Film-level system decisions (held for the whole film; mixing them is the strongest AI tell)
1. **Clock** — smooth 24/30 · on twos (12/15 fps look) · split · 60 fps for extreme zooms/morphs.
2. **Motion grammar** — ONE of: directional smear on fast moves · crisp hard steps · real shutter blur.
3. **Type** — one family (the brand's own), sentence case, scale = hierarchy (not weight); one emotional contrast line max.
4. **Accent** — greys + ONE hue with ONE meaning ("the AI is acting", "done", "yours"), on at most one element per scene.
5. **Carrier object** (optional) — must move/scale/change role at every seam; never pinned.
6. **Cursor art** (UI films) — one designed vector cursor, never the OS arrow.
7. **Overshoot budget** — at most ONE visible springy payoff in the whole film.
8. **Scale budget** — one or two moments bigger than the frame; everything else small; the ending gets *smaller* than the climax.

### Move 8 — World per act (kills "a small card on a void")
For each act write five words: **Ground** (a real surface: captured UI plate, paper, glass, concrete, a lit gradient the brand owns) · **Light** (one source, direction, falloff, plus one light event per act) · **Depth** (near/far, what is defocused) · **Texture** (grain, paper, glass, none-on-purpose) · **Sound** (bed, silence, first big hit). A flat swatch per scene is slop.

### Move 9 — Energy curve, importance budget & seams
- **Open on motion at frame 0** — never a logo, title card, "Introducing…", or empty frame.
- Beats **shorten toward the peak** (acceleration reads as arrival); hold only *after* a payoff.
- **Importance budget**: rate every beat 1–3; **≤ 25 % of beats at importance 3**. Animating every line as important is the #1 AI tell.
- Every beat gets a **"Buys:" sentence** ("Buys the belief that typing is enough: the viewer watches one real sentence sent"). If deleting it loses no belief, delete it.
- **Seams are designed first**: name the carried element + device (carried object · matched pose/velocity · same layout geometry · transition starting in A finishing in B · blur-matched cut · running VO · effect becomes environment). Cut at max velocity, never after a settle. No crossfades, no flash transitions.
- **No dead frame**: held frames keep one living thing (1–2 px/frame drift, a ticking counter). Designed breaths (0.6–1.5 s, reason stated) before a payoff are wanted.

### Move 10 — Sound arc & ending
- **Sound is direction, not decoration**: name the world sound (a tick, a latch, thumb-on-glass), the first big hit (the turn, on a downbeat), the **drop on the hero moment**, and the subtraction at the end (music filters down as the mark forms, one resolved element rings under the hold).
- Silence before the payoff is the strongest SFX available.
- **Ending**: the mark arrives **by cause** (a click, a result, the device's last link), centred, built from the last element; the final frame is the poster; end hold 0.6–1.4 s with one living thing; audio tail decays to digital silence. Never fade to black; no social-icon rows, no "Learn more".

## Part B — The Award Bar (reject on sight)

**Banned generic props** (unless the product literally is the thing): rocket, lightbulb, globe with arcs, up-and-right chart, floating phone/laptop in a void, glowing orb or sparkle for "AI", shield/padlock for security, puzzle pieces, gears, stopwatch, magnifying glass, confetti, handshake, bullseye.

**Banned copy tells**: "Not just X. It's Y." · one-word triplets ("Faster. Smarter. Yours.") · "Unlock your potential" · "Meet X" · "the future of" · "superpowers" · "seamless" · "Learn more"/"Get started free" as the last line · Title Case Benefit Lists. Write like the brand speaks, then cut half. Real UI text beats marketing text.

**Banned visual tells**: equal-length equal-energy beats · centred title page on a flat field · numbered chapters/labels/HUD chrome · accent sprayed everywhere · bounce on every pop · default dark blue/purple gradient · glow on everything · the dot-that-becomes-the-logo (unless that IS the idea) · crossfades between scenes · logo fading in from nowhere over a radial plate.

**What the winners share**: a stated reason for every choice · a cause for every joint · one hero moment · a built world · a quiet, confident ending · none of them could advertise a competitor with the logo swapped.

## Part C — Playbooks by Video Type

Each playbook gives the arc, the shapes that win, director moves, sound, the default skill stack, and the traps. Proportions are starting points; re-time freely.

### C1. Product / SaaS Launch Film (20–45 s, 16:9 + 9:16 cut)
- **Arc**: hook inside the problem (≤ 20 %) → turn = product named on a downbeat (~20–25 % mark) → 1–2 proofs as cause → action → result (35–40 %) → promise echoing a hook word (~15 %) → lockup + tail (15–20 %). Chapters variant: 3–4 chapters, each a 1–3 word flash → real UI doing it → result; strongest chapter in the 70–85 % slot.
- **Winning shapes**: UI documentary of one real task · counter as spine · typographic essay (voice-led brands).
- **Director moves**: macro camera into the single changed state; one record carried through every chapter; the success frame built first.
- **Sound**: room tone + world sound → silence before the turn → drop on the hero proof → subtract into the lockup.
- **Stack**: `motionmaxxing` (brand URL, bespoke HTML/GSAP, `brand.mjs` → `sync.mjs` → `look.py`) **or** `cinetic` (Remotion, `scripts/deck.py` deals 3 art directions, licensed music) + `motion-design`.
- **Traps**: feature tour, full browser chrome on frame 1, "Introducing…", logo opener.

### C2. Advertisement / Commercial Spot (6 s bumper · 15 s · 30 s)
- **Arc (30 s)**: tension (0–6 s) → escalation as a visible quantity (6–12 s) → turn/reveal (12–15 s) → payoff + proof (15–24 s) → brand + line (24–30 s). **15 s**: 3–5 beats, ONE idea. **6 s bumper**: one image, one action, the mark — the idea must survive at thumbnail size.
- **Winning shapes**: joke with a character · stillness that breaks · bookend · scale jump.
- **Director moves**: emotion first, product second; the product is the hero of the turn, not of every frame; give the logo a *job* (it is the button, the cursor, the knot).
- **Sound**: one musical idea with a clear downbeat on the reveal; a single signature SFX that becomes the sonic logo.
- **Stack**: `motionmaxxing` (bespoke) or `cinetic` (structured) · `blender-*` for hero product renders · Openverse/`mgaudio` + `librosa` beat grid.
- **Traps**: benefit lists, stock emotion (smiling person at phone), product on every frame.

### C3. Explainer (60–180 s; YouTube, edu, onboarding)
- **Arc**: cold open on the most surprising consequence → question → 3–5 chapters (each: claim → visual metaphor → evidence) → callback answer → one-line takeaway.
- **Winning shapes**: counter as spine · one unbroken take through a system · follow one unit (one packet, one cell, one dollar).
- **Director moves**: every number becomes a physical quantity; every abstract noun becomes an object (metaphor bank in `idea.md`); a contrast word ("but", "instead") triggers a ground/scale/camera change; mute test on every chapter.
- **Sound**: VO-led — run `whisperx` word timestamps and cut visual changes on stressed words; music low, ducked under VO.
- **Stack**: English → `anidoodle` (styles + `narrate.mjs`) or `manim` (math, `Text`/`MarkupText`); Chinese/bilingual → `huashu-art-motion` (`y1_kurzgesagt`, `y2_vox`, `t1_3b1b`, `t3_finance_chart`, `y3_whiteboard`) · `remotion-captions`.
- **Traps**: PPT-with-motion, text restating the VO, blue-purple slop palette.

### C4. Brand Sting / Logo Ident (3–8 s)
- **Arc**: gather → assemble with a physical contact → hit → wordmark → building (alive) hold.
- **Winning shapes**: the mark's primitives perform the brand verb; the mark as an object in a lit world; the world writes the name.
- **Director moves**: decide the ONE material the mark is made of and the ONE force acting on it (gravity, magnetism, tension, pour); the hit lands on frame-exact audio.
- **Sound**: one designed hit + tail; the sonic logo is ≤ 2 s and loopable.
- **Stack**: `motionmaxxing` / `cinetic` sting format · `blender-*` for material hero · `effectcraft-cli` (Lottie export for UI reuse).
- **Traps**: particle explosion into logo, lens flare, a sting longer than its idea.

### C5. Social Short / Reel / TikTok (9:16, 7–30 s, sound-off first)
- **Arc**: scroll-stopping motion in the first 0.5 s → payoff by 3 s → loop or punchline → re-watch hook (last frame feeds the first).
- **Winning shapes**: stillness that breaks · joke with a character · scale jump · seamless loop.
- **Director moves**: design for mute (on-screen type carries the story, safe zones clear of UI chrome), centre-weighted composition, one idea per clip, captions as typography not subtitles.
- **Sound**: trend-friendly beat grid via `librosa`; cuts on onsets.
- **Stack**: any primary engine in 9:16 · `remotion-captions` or `huashu-art-motion` `18-hanazi`-style variety captions · `resources/mg-styles-15/` for a fast stylized seed.
- **Traps**: horizontal film letterboxed into vertical, slow logo opener, text in platform UI zones.

### C6. Product Demo / UI Walkthrough / Feature Loop (8–90 s)
- **Arc (walkthrough)**: cold open on the end result (2–4 s) → chapters, each cause → action → result held ≥ 36 f → recap image → lockup. **Loop (4–15 s)**: rest A → cause → action → result → rest A (the end state IS the start state).
- **Winning shapes**: UI documentary of one real task · follow one record.
- **Director moves**: real UI only (never a mock dashboard), cropped by the frame and magnified by the camera (readable object ≥ 0.55 W, text ≥ 0.04 H); one designed cursor; one object per frame.
- **Stack**: `cinetic` (UI walkthrough/feature-loop formats) or `motionmaxxing` (`references/ui-demo.md`) · `reanimate` if cloning an existing product animation · `motion-design` for micro-interactions.
- **Traps**: zoomed-out full screen, cursor teleporting, enter → hold → exit loops.

### C7. Title Sequence / Opening Credits (30–120 s)
- **Arc**: tone-setting world → recurring motif evolves per credit card → motif foreshadows the story's central conflict → title card at the peak → settle into the first scene.
- **Winning shapes**: one unbroken take · typographic essay · stillness that breaks.
- **Director moves**: the motif is the device; each credit is a seam; type is integrated into the world (shadows, reflections, physical surfaces), never overlaid.
- **Stack**: `blender-*` (look-dev, `blender-time-of-day`, `blender-weather-fx`) + 2D type composite in Remotion/HTML/`effectcraft-cli` · `anidoodle` for illustrated titles.
- **Traps**: credits as lower thirds, motif repeated without evolution.

### C8. Music / Lyric Video (full song or 30–60 s cut)
- **Arc**: follows the song's form (intro / verse / chorus / bridge / drop) — chorus = visual refrain, bridge = the visual turn, final chorus = the hero moment.
- **Director moves**: `librosa` beat/onset/section grid drives every cut; `whisperx` word timing drives kinetic lyrics; one visual rule per song section; colour/ground change only at section boundaries.
- **Stack**: `anidoodle` or `resources/mg-styles-15/` styles · `three.quarks` audio-reactive particles · `remotion-captions` for lyrics · `ffmpeg` mux.
- **Traps**: cutting on every beat (exhausting), lyrics as subtitles, ignoring the song's dynamics.

### C9. Data Story / Infographic Film (30–120 s)
- **Arc**: one shocking number → zoom out to context → the mechanism → the human consequence → what changes it.
- **Director moves**: every number is a countable physical quantity (100 dots, one lit); one dataset carried through every scene; scale jumps reveal magnitude; annotations are typography, not callout boxes.
- **Stack**: `manim` (precise charts, `Text`) or `huashu-art-motion` `t3_finance_chart` · Remotion for data-driven compositions · `motion-design` for chart choreography.
- **Traps**: pie charts spinning in, chart junk, numbers as captions.

### C10. Art / Generative / Loop Piece (5–60 s)
- **Arc**: a single generative rule introduced → complexified → disrupted once → resolved into a seamless loop.
- **Director moves**: pick one style with intent (not the trendiest); deterministic `(frame, env)` so every frame is reproducible; constraint as identity (one colour change in the whole film, only three objects).
- **Stack**: `anidoodle` (32 styles, `emit.mjs` offline HTML) · `resources/mg-styles-15/` · `three.quarks` + `@react-three/postprocessing` + `tweakpane` · `blender-geometry-nodes`.
- **Traps**: noise for its own sake, loops with a visible seam, style without a rule.

### C11. Teaser / Event Promo / Countdown (≤ 15 s)
- **Arc**: withhold → partial glimpse of the device/mark → the name and the date.
- **Director moves**: show less than you have; the reveal is a single cause; the date is the hero typography.
- **Stack**: `cinetic` teaser format · `motionmaxxing` · `blender-*` for a lit hero glimpse.
- **Traps**: showing everything, generic countdown numerals.

### C12. 3D Product Hero / Turntable / Cinematic Render (10–30 s)
- **Arc**: macro detail in darkness → light reveals form → the one engineered feature performs → pull back to the full silhouette → mark.
- **Director moves**: light is the storyteller (a raking key travels across the form); camera moves on long, motivated lenses; one material close-up = hero moment; real-world scale (1 unit = 1 m).
- **Stack**: `blender-core` → `blender-workflow-recipes` → `blender-lighting-lookdev` / `blender-pbr-materials` / `blender-rendering` → `blender-asset-qa` → 2D type composite (Remotion / HTML / `effectcraft-cli`).
- **Traps**: endless 360° spin, HDRI-only flat lighting, floating product with no ground contact shadow.

## Part D — Writing Directable Shot Descriptions

Every timeline row must be directable by a stranger. Write each shot with:
1. **Picture with the text covered** — what the frame shows with no words ("a lit prompt field cropped by the right edge over a warm paper ground"). "A card on a flat colour" is a rejected answer.
2. **Cause → action → result** — what makes it move, what moves, what is still true when paused.
3. **Motion spec** — curve name + duration (from `timing-easing-tables.md`), travel distance (% W/H), camera move (push/dolly/whip/rack focus) with factor.
4. **Seam out** — carried element + its exit state (position, scale, velocity, blur).
5. **Sound sync** — the exact hit, word, or silence on this beat.

Bad: "Logo animates in smoothly with a cool glow."
Good: "The rope end (carried from beat 3, x 0.62, 4 % H) is pulled taut by an expo-out 18 f tug and ties itself into the knot mark at 0.5 W; no glow; one low rope-creak on frame 0 of the tie, then 0.9 s alive hold as the mark's shadow drifts 1 px/frame."
